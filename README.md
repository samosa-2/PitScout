# PitScout

PitScout is an offline-first FRC pit scouting web app built with HTML, CSS, and JavaScript.

## Features
- Create pit scouting reports
- Record team number, robot name, drivetrain, scout name, and notes
- Save reports in browser localStorage
- Search saved reports
- Delete reports
- Responsive layout

## Tech Stack
HTML, CSS, JavaScript, DOM APIs, localStorage

## Run
Open `index.html` in a browser.

## Future Improvements
- CSV export/import
- Edit reports
- More FRC-specific fields
- Svelte frontend
- Google Apps Script synchronization

## Development

This project was built as a learning project to practice frontend web development, JavaScript, browser storage, and Git/GitHub workflows.
